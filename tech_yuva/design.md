# Tech Yuva Design System

## Mission
Create implementation-ready, token-driven UI guidance for Tech Yuva that is optimized for consistency, accessibility, and fast delivery across the student-led innovation guild platform.

## Brand
- Product/brand: Tech Yuva
- URL: https://www.techyuva.org/
- Audience: student builders, developers, founders, hackathon participants, and community members
- Product surface: marketing site & community portal

## Style Foundations
- Visual style: cinematic, futuristic, tech-community, black & deep red theme
- Main font style: `font.family.primary=Outfit`, `font.family.stack=Outfit, Inter, sans-serif`, `font.family.mono=JetBrains Mono, monospace`
- Color palette: `color.bg=#050505`, `color.red=#c0392b`, `color.red-light=#e74c3c`, `color.text=#f5f0ed`, `color.saffron=#FF9933`, `color.green=#00c853`

## Accessibility
- Target: WCAG 2.2 AA
- Keyboard-first interactions required.
- Focus-visible rules required.
- Contrast constraints required.
- Respect `prefers-reduced-motion`.

## Writing Tone
Direct, inspiring, builder-focused, zero-fluff.
